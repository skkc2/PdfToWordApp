Output mode

Hybrid keeps the original page count by replacing complex pages in place; it does not add a duplicate appendix. Visual mode looks closest to the PDF, but page content is not individually editable. Editable mode prioritizes editable text and may change layout.

Select a PDF to begin.

Hybrid mode uses editable text on simpler pages and a page image when layout analysis detects graphics, columns or uncertain structure. Visual mode uses full-page images; editable mode reconstructs text on all pages. This is not a pixel-perfect editable conversion engine; tables and complex layout may need further reconstruction. Scanned PDFs require OCR for editable text. Limits: 30 MB, 300 pages.
